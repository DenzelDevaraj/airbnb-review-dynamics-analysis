# Unlocking Airbnb Review Dynamics in New York

## Project Overview
Analysis of Airbnb listing performance in New York City, identifying the key drivers of guest review frequency using exploratory data analysis, sentiment analysis, and predictive modelling. Findings were visualised in an interactive  Power BI dashboard to generate actionable recommendations for hosts.

## Tools & Technologies
- **Python** — data cleaning, OLS regression modelling, sentiment analysis
- **Power BI** — interactive dashboard visualising pricing, sentiment, and engagement trends
- **Libraries:** Pandas, Statsmodels, Scikit-learn, Matplotlib, Seaborn

## Key Findings
- Built an OLS regression model to predict reviews per month, using features including price, room type, accommodation size, review scores, guest sentiment, and instant bookability
- Identified **instant bookability** and **guest sentiment** as notable drivers of review frequency
- Hotel rooms generated the highest average guest sentiment (0.44)
- Average listing price: $157.91 | Average review score: 94/100
